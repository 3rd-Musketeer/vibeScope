# Extension Icons

This directory should contain the extension icons in three sizes:

- `icon16.png` - 16x16 pixels (toolbar icon)
- `icon48.png` - 48x48 pixels (extension management)  
- `icon128.png` - 128x128 pixels (Chrome Web Store)

## For Development

During development, you can use any placeholder images or create simple colored squares.

For production, create professional icons that represent the Social Media Research Assistant:
- Use consistent colors (blue theme: #007bff)
- Include search/research iconography (magnifying glass, document, etc.)
- Ensure icons are clear at all sizes
- Follow Chrome extension icon guidelines

## Quick Placeholder Generation

You can create placeholder icons using any image editor or online tools:
1. Create 128x128 blue square with white search icon
2. Resize to create 48x48 and 16x16 versions
3. Save as PNG format
